# 🧠 Prediction of Diabetes through Machine Learning

A machine learning project using Python to predict diabetes from medical records (PIMA Indian dataset). This project applies classification algorithms and features an interactive Tkinter-based GUI.

## 📌 Features

- Predicts diabetes based on 8 health attributes
- Tkinter GUI for user-friendly interaction
- Model trained on real-world healthcare dataset
- Visual data analysis with charts and graphs

## ⚙️ Technologies Used

- **Language:** Python  
- **Libraries:** scikit-learn, TensorFlow, Pandas, NumPy, Matplotlib  
- **Tools:** Jupyter Notebook, Tkinter

## 📊 Dataset

- **Source:** PIMA Indian Diabetes Dataset (UCI ML Repository)
